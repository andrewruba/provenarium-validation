# Provenarium Validation v0.1.0

First installable prerelease of the local requirements → protocol → approval →
execution → evidence workflow.

## Install

Requires **Node.js 26 and npm on macOS or Linux**. One npm archive serves both
platforms; npm downloads the runtime dependencies for the current platform.

```sh
npm install --global https://github.com/andrewruba/provenarium-validation/releases/download/v0.1.0/provenarium-validation-0.1.0.tgz
provenarium browser install
provenarium --version
```

Alternatively, download the `.tgz` asset and `SHA256SUMS`, verify with
`shasum --algorithm 256 --check SHA256SUMS` on macOS or
`sha256sum --check SHA256SUMS` on Linux, then run
`npm install --global ./provenarium-validation-0.1.0.tgz`.
Chromium setup is separate; Linux may also require Playwright system dependencies.
See the [installation guide](https://github.com/andrewruba/provenarium-validation/blob/v0.1.0/docs/installation.md).

## Included

- YAML requirements, linked context, and selectable OpenAI/Anthropic authoring.
- Reviewed qualification protocols, immutable approvals, and deterministic
  Playwright execution with retained observations and evidence.
- HTML/PDF reports and CSV traceability.
- Synthetic examples plus corrected and deliberately faulty scientific demos.
- `provenarium uninstall`, with `--dry-run` and `--yes` options. Removal preserves
  projects, reports, saved credentials, and shared browser files.

## Verification and scope

The exact attached archive is installed and verified on macOS and Ubuntu before
publication, including the good/defective qualification workflow, global CLI
installation, and uninstall behavior. `release.json` identifies the source commit
and archive digest; `SHA256SUMS` checks the downloaded archive.

This is a prerelease: live OpenAI and Anthropic authoring-quality evaluations
remain pending. Routine checks make no provider calls. Windows is not currently
verified. Dependencies and Chromium require network access during installation;
this is an npm archive, not a bundled standalone executable. The package is not
published to the npm registry.
