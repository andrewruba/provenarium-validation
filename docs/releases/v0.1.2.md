# Provenarium Validation v0.1.2

This prerelease introduces the guided `validate` flow. It drafts and reviews
requirements, creates a readable IOQ and Playwright tests, dry-runs the suite,
and produces the execution report after the checks pass.

## Install and run

Use Node.js 26 and npm on macOS or Linux.

```sh
npm install --global https://github.com/andrewruba/provenarium-validation/releases/download/v0.1.2/provenarium-validation-0.1.2.tgz
provenarium --version
provenarium validate --context ../my-app --url https://app.example.com
```

Run `provenarium validate` from an existing validation project to reuse its
requirements and matching IOQ. The CLI provisions Chromium when needed.
Use `--provider openai` or `--provider anthropic` to select the authoring provider.

## Changes

- The dry run applies browser-confirmed locator fixes together and reruns the
  suite once with the original expected results. This includes alert and status
  checks that use visible message text.
- A failed dry run saves the IOQ and an HTML report with expected and observed
  results. Formal execution starts after the dry run passes.
- The hosted dilution demo reports unreadable browser storage without showing an
  empty register. The faulty comparison build retains its seeded defects.

The release workflow verifies the same npm archive on macOS and Ubuntu.
`release.json` identifies the source commit, and `SHA256SUMS` verifies the
downloaded archive.
